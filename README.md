# Aseel's Portfolio (React + Tailwind)
1. `npm install` then `npm run dev`
2. Edit the CONFIG block at the top of `src/App.jsx` (email, phone, LinkedIn, GitHub, CV link).
3. Add projects / skills / certificates by editing the PROJECTS, SKILLS and CERTS arrays.
   - Certificate images: put files in `public/` and set `img: "/cert.png"`.
4. Deploy: `npm run build`, then upload `dist/` to Vercel / Netlify / GitHub Pages.
